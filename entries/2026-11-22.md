# 2026-11-22

## [Veille] Cisco BroadWorks : XXE exploitée ajoutée au KEV (CVE-2026-20320)
- Quoi : XXE dans le parseur XML de l'Open Client Interface (OCI) de Cisco BroadWorks (CVSS 7.5), permettant à un attaquant non authentifié de lire des informations de configuration sensibles. Ajoutée au catalogue KEV de la CISA avec une faille Openwave Messaging (CVE-2026-111793), échéance fédérale au 24/11/2026.
- Pourquoi : Malbear Labs l'associe à une campagne (« Operation Snowball ») contre un opérateur télécom européen, avec vol de clé privée système et de données d'abonnés ; correctif disponible depuis août 2026.
- À retenir : ne jamais exposer les interfaces d'administration/provisioning VoIP (OCI, XSP) sur Internet, et appliquer les correctifs Cisco d'août 2026.
- Source : https://thehackernews.com/2026/11/cisco-broadworks-and-openwave-flaws.html

## [Note] Web : comprendre les attaques XXE (XML External Entity)
Une XXE survient quand un parseur XML résout les entités externes déclarées dans un DTD fourni par l'utilisateur.
L'attaquant déclare une entité pointant vers un fichier local ou une URL interne, puis la référence dans le document :
```xml
<?xml version="1.0"?>
<!DOCTYPE r [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]>
<r>&xxe;</r>
```
Impacts : lecture de fichiers, SSRF (`SYSTEM "http://169.254.169.254/"`), exfiltration hors bande via DTD externe quand la réponse n'est pas reflétée (XXE « blind »), voire DoS (« billion laughs »).
Surfaces souvent oubliées : SOAP, SVG uploadés, fichiers DOCX/XLSX (ZIP de XML), endpoints acceptant `Content-Type: application/xml`.
Défense : désactiver DTD et entités externes dans le parseur. En Python, préférer `defusedxml` ; en Java, `factory.setFeature("http://apache.org/xml/features/disallow-doctype-decl", true)`.

## [Note] Détection : repérer le Kerberoasting dans les journaux AD
Le Kerberoasting consiste, pour tout utilisateur du domaine, à demander des tickets de service (TGS) pour des comptes ayant un SPN, puis à casser hors ligne la partie chiffrée avec le hash du compte de service.
Signal principal sur les DC : l'événement 4769 (demande de ticket de service), en particulier avec `Ticket Encryption Type = 0x17` (RC4-HMAC), plus facile à casser que l'AES (0x11/0x12).
Heuristiques utiles : un même compte demandant des TGS pour de nombreux SPN en peu de temps, du RC4 dans un domaine où l'AES est la norme, des demandes vers des comptes de service rarement utilisés.
Côté attaquant (pour tester sa détection en labo) : `impacket-GetUserSPNs corp.local/alice -request -dc-ip 10.0.0.10`.
Défense : mots de passe longs et aléatoires ou gMSA pour les comptes de service, imposer l'AES (`msDS-SupportedEncryptionTypes`), et un compte « honeypot » avec SPN dont toute demande de ticket déclenche une alerte.
