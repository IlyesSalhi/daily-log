# 2026-11-24

## [Veille] LiteLLM : RCE via l'endpoint de test des guardrails, ajoutée au KEV (CVE-2026-40217)
- Quoi : la CISA a ajouté le 18/11/2026 au catalogue KEV une faille du proxy LLM BerriAI LiteLLM permettant une exécution de code à distance via l'URI `/guardrails/test_custom_code` (réécriture de bytecode). Échéance fédérale : 2 décembre 2026.
- Pourquoi c'est important : d'après GTIG (cité par la presse), des attaquants ont transformé de simples clés d'inférence limitées en identifiants d'administration complets puis se sont installés durablement. Une passerelle LLM concentre les clés API de tous les fournisseurs de modèles.
- À retenir côté défense : mettre LiteLLM à jour, ne pas exposer l'interface d'administration ni les routes de test sur Internet, et faire tourner toutes les clés fournisseurs stockées sur une instance exposée.
